## Gradients

Two gradients were derived and added to `globals.css`.

### Background gradient

```css
--gradient-bg: linear-gradient(135deg, oklch(0.13 0.01 100) 0%, oklch(0.16 0.02 115) 100%);
```

Use for shell backgrounds and large hero sections. Keep text contrast on solid cards above it.

### Accent gradient

```css
--gradient-accent: linear-gradient(to right, oklch(0.88 0.19 105) 0%, oklch(0.72 0.23 28) 100%);
```

Use for high-energy CTAs, map/event accents, and premium badges. This is the main place the Lava Sprint warmth enters the brand.

## Tone and voice

### Words to use

Loose, confident, internet-native copy. Short commands, fast verbs, and a little swagger are good. The product should sound like it knows it is a game first and a wallet product second.

### Words to avoid

Avoid corporate crypto language, fake-finance seriousness, and over-explaining jokes. No “synergize”, “unlock”, “seamless”, or empty hype filler.

### Voice example

> queue up, eat fast, don’t get boxed in.

## Usage dos and don'ts

**Do:**

- Use Electric Citrus yellow-green for primary UI actions and Lava Sprint orange for map danger, heat, and late-match urgency.
- Keep the shell dark by default.
- Use Fraunces sparingly for hero/display headings only; keep dense UI on Inter.
- Use IBM Plex Mono for numbers, ids, addresses, countdowns, and any stat that updates.
- Keep cards and overlays mostly solid; let gradients sit behind them, not under dense text.

**Don't:**

- Don’t reintroduce generic cyan-on-dark crypto styling.
- Don’t put body copy directly on the accent gradient.
- Don’t use Fraunces for buttons, forms, or dense dashboard text.
- Don’t make every accent orange; orange is reserved for hazard and arena energy.
- Don’t hardcode colors in components; extend the token layer instead.
